## 파일
- `index.html` — 화면 전체(로그인 · 연습 · 조항 · 오답 · 순위표)
- `data.js` — 기본 개념 데이터(조항 카드 47개, 바른 표기 문제). `tools/orth_data.py`로 만든다.
- 데이터 파일 셋(data.js·school.js·spot.js)은 `tools/pack.py`로 싸여 있어 열어 봐도 바로 읽히지 않는다(복제 방지). 원본은 tools/*.py, 푸는 코드는 index.html의 `ORTH_UNPACK`.
- `tools/orth_data.py` — 조항 원문·예시·문제 원본. 고친 뒤 `python3 tools/orth_data.py data.js`
- `school.js` — 학교별 시험 범위(교과서·프린트·올림포스·클리닉). `tools/school_data.py`로 만든다(클리닉 낱말은 `tools/clinic_words.py`).
- `tools/school_data.py` — 학교 자료에서 뽑은 문제와 자료별 조항 목록. 고친 뒤 `python3 tools/school_data.py school.js`
- `spot.js` — '틀린 곳 찾기' 대화 문제. `tools/spot_data.py`로 만든다. 고친 뒤 `python3 tools/spot_data.py spot.js`
- `logo.webp` — 크레파스 캐릭터(홈·결과·로그인 말풍선)
- `server/orth.gs` — 내신 클리닉 트래커 Apps Script에 덧붙이는 파일(로그인·기록·순위). Code.gs·omr은 그대로 둔다.
- `char.webp` — 캐릭터 이미지

## 화면
- 글꼴 Pretendard(자간 -3%, 글자 크기 짝수), 제목만 주아체. 색은 로고 빨강 하나: 맞으면 빨간 체크, 틀리면 회색 줄긋기 + 빨간 교정.
- 홈: 캐릭터 한마디(순위·학교 대항 상황별) → 시작 버튼 → 설정 요약 한 줄('바꾸기'로 펼침) → 학교 대항 → 순위표 → 오늘/누적/오답.
- 유형: 바른 표기 / 쓱쓱 넘기기 / 틀린 곳 찾기(대화 속 틀린 표기 눌러 찾기, 전부 맞혀야 정답) / 쓱쓱 넘기기(문장 하나, 맞으면 오른쪽·틀리면 왼쪽으로 넘기기).
- 오답 탭: 위는 지금 오답(다시 맞히면 빠짐), 아래는 '자주 틀린 단어'(바른 표기 문제에서 고르기·쓱쓱 합쳐 2번 이상 틀린 단어, 다시 맞혀도 익혀도 남음, 많이 틀린 순 20개 + '외 n개', '자주 틀린 단어만 풀기' 최대 15문제). 서버의 단어별 맞힘/틀림 횟수(st)로 계산하므로 서버 변경 없음.
- 연속 일수는 이 기기 기준(localStorage).

## 로그인·순위표
- 트래커 계정(이름·비밀번호 4자리) 그대로 로그인. 학교는 계정에 등록된 학교로 정해진다.
- 한 번 로그인하면 그 폰에서 30일 유지(쓰면 연장). 비밀번호가 바뀌거나 퇴원 처리되면 풀린다.
- 트래커에 로그인돼 있는 폰이면 이름을 다시 안 쳐도 된다.
- 도장: 단어마다 3개. 날짜가 다르고 10시간 이상 지나야 다음 도장(같은 날 여러 번 맞혀도 1개, 자정 넘겨 바로 풀어도 안 찍힘). 틀리면 그 단어 도장이 다 지워진다(직접 쓰기에서 틀린 건 빼고). 3개가 다 찍히면 '익힌 단어'.
  도장 계단: 쓱쓱 넘기기로는 1개까지, 바른 표기 고르기로는 2개까지, 3개째는 '직접 쓰기'(틀린 표기를 보고 바르게 쳐서 맞혀야). 연습에서는 도장 2개이고 오늘 찍을 수 있는 단어가 직접 쓰기 문제로 나온다.
  틀리면 바른 표기를 그대로 한 번 써야 다음 문제로 넘어간다(고르기·짝 문장·쓱쓱·직접 쓰기 모두).
  복습 도장: 익힌 단어(도장 3개)는 7일이 지나면 다시 나오고, 고르기·쓰기로 맞히면 이번 주 도장 1개(`rev`, 주 시작 때 0). 틀리면 똑같이 도장이 지워진다. 거의 다 익힌 학생도 이번 주 순위에 길이 있게.
  연습 순서: 오늘 도장 받을 수 있는 단어 먼저(쓰기 차례인 단어가 더 먼저, 7일 지난 익힌 단어도 같은 무게), 오늘 도장을 못 받는 단어(오늘 이미 받음·쓱쓱 상한·7일 안 된 익힌 단어)는 받을 문제가 모자랄 때만 채움(화면 `weight`·`sample`). 결과 화면에 맞혔는데 도장을 못 받은 까닭을 적어 줌(`noStLine`).
  쓱쓱(o+번호)과 바른 표기 고르기(번호)는 같은 단어로 센다. 서버 `run`(단어별 도장 수)·`rd`(마지막으로 찍은 때, 시간 번호)·`kan`(도장 합)·`kan0`(주 시작 때 도장 합). 기록은 `[문제, 맞음, 초, 유형(s/p/t)]`.
- 순위표: 우리 학교 / 전체 × 이번 주(월요일 0시부터, 이번 주에 모은 도장 + 복습 도장) / 누적(지금까지 모은 도장). 익힌 단어 수는 홈 내 기록 칸에만.
- 홈 '오늘 도장 받을 단어': 지금 범위에서 오늘 찍을 수 있는 단어 수와 목록(두 표기를 섞어 보여 줌, 바른 표기만 보여 주면 외우고 풀어서). '풀기'는 그중 15개.
- 바른 표기 고르기: 정답·오답이 서로 뒤바뀐 짝(반드시/반듯이 ↔ 반듯이/반드시)이 같은 범위에 있으면 ①② 두 문장을 같이 내고, 둘 다 맞아야 맞음.
- 학교 대항: 학교 전체 도장 합계 ÷ 인원(이번 주 / 누적). 나누는 인원은 학교별 보정(동양 35명까지, 경복 13명 이상, 명덕 16명까지, 나머지는 재원생 수 그대로 — 화면 `VS_ADJ`). 서버가 학교별 재원생 수·참여 수·합계를 돌려주고 화면에서 줄 세운다.
- 기록은 트래커 시트의 `orth` 탭에 학생마다 한 줄. 이름 가리기는 `server/orth.gs` 맨 위 `ORTH_MASK_NAME`.
- 이름을 치면 서버가 처음 로그인(비밀번호 0000)인지 알려 줘서, 처음인 학생에게만 0000 안내가 나온다(orthLookup).
- 👻(로그인 화면 '선생님 페이지' 옆): 졸업생 입장. orth.gs 맨 위 ORTH_GHOST_CODE(배포된 Apps Script에만 적어 둠)를 치면 계정 없이 기본 개념 전체를 풀 수 있다. 순위·학교대항전엔 안 들어가고 기록은 그 폰에만 남는다.
- 학생은 로그인 필수. 첫 화면의 '선생님 페이지'는 트래커 선생님 비밀번호로 들어가서 학교를 골라 학생 화면 그대로 보고, 그 학교 순위표(학교/전체 × 이번 주/누적)를 본다. orth.gs가 있으면 30일 유지(orthTeachLogin), 없으면 트래커 토큰 6시간.

## 학교별 범위
- 연습 화면 '범위'에서 기본 개념 / 교과서 / 프린트 / 올림포스 / 클리닉을 골라 섞어 푼다. 처음엔 그 학교에 있는 범위가 전부 켜져 있다.
- 기본 개념 = 공통 문제 전체(장별로 고를 수 있음). 교과서·프린트·올림포스 = 그 자료에서 뽑은 문제 + 그 자료가 다루는 조항의 공통 문제 전부. 클리닉 = 그 학교 클리닉(무한선지)에 나온 예시 낱말만(공통 문제는 안 끌어옴). 뜻으로 가르는 짝(`ns`)은 쓱쓱 넘기기에서 뺀다.
- 자료에서 뽑은 문제는 문제 위에 '교과서 118쪽', '프린트 7쪽'처럼 위치가 나온다. 조항 탭에는 시험 범위 조항에 '교과서·프린트' 표시.
- 학교마다 자료 연결은 `tools/school_data.py` 맨 아래 `SCHOOLS`. 비어 있는 자리는 화면에 '준비 중'.

## 서버 붙이기(한 번만)
1. 트래커 Apps Script 편집기 → 파일 ＋ → 스크립트 → 이름 `orth` → `server/orth.gs` 내용 붙여 넣기 → 저장
2. 함수 목록에서 `orthCheck` → 실행 → 실행 로그에 "모두 정상"
3. 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포 (웹 앱 주소 그대로)
