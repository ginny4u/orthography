# 맞춤법 교정실

고1 한글 맞춤법 반복 연습 사이트. 주소: https://ginny4u.github.io/orthography/

## 파일
- `index.html` — 화면 전체(로그인 · 연습 · 조항 · 오답 · 순위표)
- `data.js` — 공통 범위 데이터(조항 카드 45개, 바른 표기 문제, 조항 빈칸). `tools/orth_data.py`로 만든다.
- `tools/orth_data.py` — 조항 원문·예시·문제 원본. 고친 뒤 `python3 tools/orth_data.py data.js`
- `server/orth.gs` — 내신 클리닉 트래커 Apps Script에 덧붙이는 파일(로그인·기록·순위). Code.gs·omr은 그대로 둔다.
- `char.webp` — 캐릭터 이미지

## 로그인·순위표
- 트래커 계정(이름·비밀번호 4자리) 그대로 로그인. 학교는 계정에 등록된 학교로 정해진다.
- 한 번 로그인하면 그 폰에서 30일 유지(쓰면 연장). 비밀번호가 바뀌거나 퇴원 처리되면 풀린다.
- 트래커에 로그인돼 있는 폰이면 이름을 다시 안 쳐도 된다.
- 순위표: 우리 학교 / 전체 × 이번 주(월요일 0시부터) / 누적. 맞힌 문제 수, 같은 문제는 하루 한 번만 센다.
- 기록은 트래커 시트의 `orth` 탭에 학생마다 한 줄. 이름 가리기는 `server/orth.gs` 맨 위 `ORTH_MASK_NAME`.
- '로그인 없이 둘러보기'는 학교만 골라 이 폰에만 저장(순위표 없음).

## 서버 붙이기(한 번만)
1. 트래커 Apps Script 편집기 → 파일 ＋ → 스크립트 → 이름 `orth` → `server/orth.gs` 내용 붙여 넣기 → 저장
2. 함수 목록에서 `orthCheck` → 실행 → 실행 로그에 "모두 정상"
3. 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포 (웹 앱 주소 그대로)

## 기준
- 조항 원문과 예시: 국립국어원 「한글 맞춤법」(2017)
- 범위: 제1·2항, 제5~23항, 제25~31항, 제34~36항, 제39~48항, 제51·53·56·57항 (표준 발음법 제외)
